### 🛠️ Meus Projetos em Destaque

Plataforma escalável para automação logística de pedidos desenvolvida em arquitetura de **Microsserviços** com **Java** e **Spring Boot**.

* Estilização moderna e totalmente adaptável com **Tailwind CSS**.
* Estruturação de rotas dinâmicas isolando a área do cliente da área administrativa de estoque.
